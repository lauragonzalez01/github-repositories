# GitHub Repository Finder

Angular web app for searching and viewing public GitHub repositories. Allows you to log in as a developer. Responsive design.

## Execution

1. Open the **terminal** in the project folder.
2. Run: `npm i`
2. Run: `npm start` (it will open in `http://localhost:4200`).

## Requirements

* **Node.js**
* **npm**
* **Angular CLI** (`npm install -g @angular/cli@18`)

## Usage

* Enter a GitHub username or use "Log in as Developer".
* Filter repositories by name, language, and stars.
* View repos on GitHub with the button.
